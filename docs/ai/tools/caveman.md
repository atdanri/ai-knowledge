# Caveman
[🔙README](/README.md)

With Caveman, agents and skills are used to minimise communication with the chat in order to save tokens. 
This works quite well, for example, on large projects. For very small tasks, however, Caveman can lead to increased token consumption, as the Caveman files naturally increase the context. It’s definitely worth taking a look at.
