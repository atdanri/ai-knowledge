# personal opinion on Copilot
[🔙README](/README.md)

In my opinion, Copilot isn’t one of the most powerful public AI development tools, although the gap isn’t super wide. However, it does have clear advantages. These include its widespread use and, consequently, a large knowledge base. There are also various plugins that allow Copilot to run within the most popular development environments(eg. IntelliJ). Unlike some other tools, it doesn’t require a separate IDE(but is default included in vscode).

I’d say it’s a good all-round tool for the majority of developers, though it doesn’t come with as many built-in features for certain development processes as some other tools do. On the other hand, you don’t have to delve as deeply into specific quirks as you do with some other tools(learning curve).

> *While this repository was being created, I found the Plan Agent for Copilot. It is by no means identical to Kiro’s spec mode, but it attempts to achieve something similar. As it is simpler to use, it is very well suited to small and medium-sized adjustments where using Kiro’s spec mode might, in some cases, be too cumbersome. Give it a try!*
