## documentation
These tools can be useful in various areas of documentation work. This ranges from reading and editing to small-scale creation. It doesn’t matter whether the documentation is technical, inline comments, etc. (personally, I would only use the tools as a support tool for user documentation). It is important that the tools always have the context required for the task at hand. If you have specific ideas about the documentation, ensure that the AI tool receives this as context. For example, when using Copilot, you could specify in the ‘copilot-instructions.md’ file in which cases inline/class/function comments should be generated and how they should be structured.
