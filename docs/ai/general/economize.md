## tips
- use the inline chat in AI developer tools where possible, local issues that don’t require much context can be dealt with using far fewer tokens
- use new chat sessions for differnt tasks with different context. Otherwise, the old context would cause you to use up more tokens and might have a negative impact on the responses
- If you find it useful or necessary to save tokens, use freely available AI chatbots or a standard search engine for simple tasks and researches
