# kiro cli - knowledge
[🔙README](/README.md)

In the Kiro CLI, ‘knowledges’ can be created as an experimental feature, allowing a wealth of context to be made available (such as entire documentation sets from larger projects) – this works very well, but the knowledge entries are only available within the Kiro CLI – for this reason, I would personally lean towards a local MCP server that offers similar functionality - [kiro CLI knowledge management](https://kiro.dev/docs/cli/experimental/knowledge-management/)
